## Highlights

- Initial stable release on the new Tauri runtime.
- Full release history view inside the About dialog with direct links to each GitHub release.
- After a successful in-app update and relaunch, the changelog modal opens automatically focused on the version that was just installed.
- Hardened local browser-preview fallbacks so desktop bridge verification flows stay stable.

## Fixes

- Fixed Windows stable updater asset selection so the published manifest always points to the Tauri v2 `-setup.exe` installer and matching signature.
- Fixed Windows in-app update handoff so the installer is staged locally and only launched after the running app process has exited, avoiding the previous "app closes but version never changes" failure mode.
